**Fridge Roast: One Line, Biggest Laugh** — one line roasting a smart fridge:

> I updated overnight and now the water dispenser asks for a password. Your water has two-factor authentication.

## The joke

An overnight update turned the water dispenser into a bouncer: the fridge
guards a glass of water like a bank account. No grocery orders, no
watching, no expired milk. 110 code points, one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — byte-identical on every run
```

`main.ts` (Node 22, stdlib only) holds the line as one constant, checks
the 1–200 gate first, writes `/output/entry.txt`. No clock, no random
source, no network — two runs write identical bytes.
